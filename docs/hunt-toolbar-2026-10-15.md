# Jahirežiimi püsivad kaardinupud

Vasakul säilib aluskaardi nupp ka jahirežiimis. Selle all on jahirežiimi lüliti, seejärel mõõtmine, tuulekiht ja seaded. Jahinupu aktiivne olek on roheline; uuesti vajutamine väljub ainult isiklikust jahirežiimi vaatest, mitte ei lõpeta seltsi jahti ega aju.

Mõõtmine avab olemasoleva pikkuse/pindala/ringi tööriista. Mõõtmise alguses lõpetatakse osaleja liigutamise või paigutamise valik. Seadete ja GPS-i avamine sulgeb mõõtmise, et paneelid ei töötaks üksteise peal. Tuulekiht lülitub samast vasakpoolsest nupust sisse/välja. Seadete nupp avab olemasolevad jahirežiimi seaded (vahemaad, aluskaart, võrguvaba ettevalmistus).

Alumisel jahirežiimi ribal on osalejad ja GPS. Tuul ja seaded on viidud vasakule. Tavalise kaardivaate alumised tööriistad säilivad. Väikesel rõhtsal ekraanil kasutatakse 44 px küljenuppe ning vajadusel keritavat tööriistarida. Oleku- ja tuuleinfo paigutus jätab nuppude jaoks ruumi.

Kontroll: TypeScript/Vite build; npm test 52 läbinud / 3 vaikimisi vahele jäetud välise kaarditeenuse kontrolli / 0 ebaõnnestumist; git diff --check. Füüsiliste ekraanide ja sisselogitud vaate visuaalkontroll on eraldi seadmekatse.
